# AI Memory Research Lab

这是一个面向芯片技术预研的 AI 记忆（AI Memory）学习、调研与原型项目。

## 研究问题

> 在真实自主 Agent 中，哪些记忆操作会成为延迟、带宽、能耗、容量或数据治理的瓶颈？哪些部分适合通过软硬协同改善？

项目将同时关注两条相关但不同的路线：

1. **模型运行时记忆**：KV Cache、长上下文，以及推理阶段的显存和带宽问题。
2. **Agent 长期记忆**：跨会话的事实、事件、偏好、经验与规则；包括写入、组织、检索、更新、遗忘与评测。

前期重点是第二条，并保留与第一条协同的接口。

## 路线图

| 阶段 | 目标 | 主要产出 |
| --- | --- | --- |
| 01 基础学习 | 建立 LLM、推理、RAG 与 Agent 的共同语言 | 学习笔记、术语表、最小示例 |
| 02 前沿调研 | 梳理长期记忆机制、评测与开源实现 | 论文卡片、技术地图、问题清单 |
| 03 基准与画像 | 构建可重复的 memory sandbox 并采集端到端 trace | 指标定义、基线、性能画像 |
| 04 架构预研 | 验证软硬协同假设 | 设计文档、模拟原型、实验报告 |

## 最小系统（Memory Sandbox）

同一数据、模型与上下文预算下，对比：

- 全历史上下文；
- 基础 RAG；
- 混合检索（关键词 + 向量 + 时间/元数据）；
- 结构化长期记忆（事实、事件、规则分层）。

除回答质量外，统一记录检索召回、写入/检索/重排/上下文组装时延、token 成本、存储访问、索引规模、写放大和能耗代理指标。

## 工作约定

- 每篇论文用一张“论文卡片”沉淀问题、机制、证据、局限和对芯片的启发。
- 每次实验写明模型、数据集、上下文预算、评测器与随机种子，避免不可比较的结论。
- 关键技术取舍记录在 `docs/decisions/`，避免背景和理由随讨论丢失。
