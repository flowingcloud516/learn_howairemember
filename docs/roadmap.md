# 研究路线图

## 0. 定义边界

AI 记忆不等于向量数据库，也不等于 KV Cache。本项目把它视为一个闭环：

`观测 → 写入/更新 → 组织/压缩 → 检索 → 上下文组装 → 推理/行动 → 评测/遗忘`

## 1. 基础学习（第 1–6 周）

- Transformer、token、embedding、attention、KV Cache 与 context window。
- 推理工程：prefill/decode、batching、量化、吞吐、时延、显存与带宽。
- RAG：chunking、稠密/稀疏检索、重排、上下文组装。
- Agent：工具调用、状态机、短期状态和长期记忆。
- 长期记忆：事实、事件、规则；时间、冲突、遗忘、权限和溯源。
- 评测：质量、证据召回、成本、尾延迟与资源画像。

每周至少完成一个可运行的小实验，而不只做阅读。

## 2. 技术调研（第 3–10 周）

优先回答：

1. 长期 Agent memory 的读写路径分别包含哪些操作？
2. 哪些数据结构和访问模式主导 P50/P99 时延、DRAM/SSD 流量及能耗？
3. 记忆更新、冲突消解、删除和时间推理如何改变系统设计？
4. 现有公开基准覆盖了什么，又遗漏了什么？

## 3. 基准与性能画像（第 7–14 周）

先实现基线，再讨论硬件：

- No-memory/full-context；
- lexical、dense 和 hybrid retrieval；
- fact/event/procedure 三类结构化记忆；
- LongMemEval、LoCoMo 与内部芯片研发助手任务集。

## 4. 候选架构方向

- 分层记忆：热状态、近期事件、长期事实和原始证据归档。
- 时间与版本感知索引：更新、失效、冲突、可定向删除。
- 经验复用：为工具型 Agent 保存成功案例和可执行策略。
- 端侧/私域记忆：低功耗 embedding、私有检索、加密与可信删除。

架构立项需同时给出质量、性能、能耗和安全/隐私收益的可证伪假设。
